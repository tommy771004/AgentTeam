# Open Design bundled templates

This directory vendors template source files, prompt templates, and bundled
preview assets from https://github.com/nexu-io/open-design at commit `4567a0d`.

Included source trees:

- `design-templates/`
- `prompt-templates/`
- `plugins/_official/image-templates/`
- `plugins/_official/video-templates/`

The upstream repository license is included as `LICENSE`. Individual template
directories retain their upstream `LICENSE` files where they apply, including
the MIT-licensed `guizang-ppt` and `html-ppt` families. Do not remove or alter
those notices when redistributing these files.
