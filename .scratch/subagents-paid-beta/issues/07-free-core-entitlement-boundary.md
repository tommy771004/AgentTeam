# 07 — 建立 Free Core Entitlement Boundary

**What to build:** Make the Free Core useful without login while giving every future paid capability one consistent entitlement decision point.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] The app starts and completes baseline local coding tasks without a subscription or account.
- [ ] Free Core includes local provider/CLI connections, projects, sessions, basic multi-agent use, Plan/Goal tasks, permissions, skills/MCP, diff/terminal/history, export, and Handoff.
- [ ] Paid capability checks resolve through one entitlement boundary rather than scattered feature-specific flags.
- [ ] An unavailable or malformed entitlement fails closed for paid features without blocking Free Core launch.
- [ ] Existing local data remains readable and exportable regardless of entitlement state.
- [ ] Free and entitlement-denied behavior is covered through UI and runtime seams.
