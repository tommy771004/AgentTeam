# AgentStudio 隱私權政策（Privacy Policy）

> 狀態：**Draft 草稿** — 公開前需法務審閱；生效日期待定。

## 我們的原則

AgentStudio 是 local-first 桌面應用。**預設情況下，我們收集不到你的任何資料**，
因為沒有任何對話、檔案或憑證會傳送到我們的伺服器。

## 我們處理的資料

| 類別 | 內容 | 法律依據 / 目的 |
| --- | --- | --- |
| 授權與訂閱 | 電子郵件、訂閱狀態、裝置啟用記錄 | 履行合約（付費功能） |
| 更新查詢 | 版本、平台、架構（不含識別碼） | 正當利益（軟體更新） |
| 客服往來 | 你主動提供的內容 | 履行合約 / 同意 |

我們**不**收集：對話內容、提示詞、工具輸出、檔案、API 金鑰、使用行為遙測。

## 第三方

- 你設定的 LLM 供應商、MCP server 與連接器由**你**選擇並直接連線；
  其資料處理適用**該供應商**的條款，請自行審閱。
- 付款由第三方金流（待定）處理；我們不儲存卡號。

## 你的權利

依 GDPR / CCPA / 個資法（依你所在地區適用），你可請求存取、更正、刪除
我們持有的帳務資料。本機資料的刪除方式見《資料保存與刪除》。

## 兒童

本產品不面向 16 歲以下使用者。
