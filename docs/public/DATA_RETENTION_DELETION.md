# SubAgents AI 資料保存與刪除（Data Retention & Deletion）

> 狀態：**Draft 草稿** — 公開前需審閱。

## 本機資料（你的裝置）

所有執行資料都在你裝置的應用資料夾（Windows：`%APPDATA%/SubAgents AI`；
macOS：`~/Library/Application Support/SubAgents AI`）：

| 資料 | 保存 | 刪除方式 |
| --- | --- | --- |
| 對話與執行日誌 | 無限期（本機） | 應用內刪除討論串，或移除資料夾 |
| 排程 / 事件定義 | 至你刪除為止 | 應用內管理頁刪除 |
| Hermes 技能與記憶 | 衰減/整併機制自動精簡 | Learning 頁刪除；或清除資料夾 |
| 憑證 vault（加密） | 至你清除為止 | 設定 → 連接器 → 清除；或移除 vault 檔 |
| 執行快照（rewind） | 依設定輪替 | 應用內清除 |

**完整刪除**：解除安裝並移除上述資料夾＝所有資料永久消失。我們沒有副本，
無法為你還原 — 請善用「匯出設定包」自行備份。

## 我們伺服器上的資料（僅帳務）

| 資料 | 保存 | 刪除 |
| --- | --- | --- |
| 帳號與訂閱記錄 | 訂閱期間 + 法定帳務年限 | 來信請求，法定保存項目除外 |
| 裝置啟用記錄 | 訂閱期間 | 隨帳號刪除 |
| 客服信件 | 2 年 | 來信請求 |
