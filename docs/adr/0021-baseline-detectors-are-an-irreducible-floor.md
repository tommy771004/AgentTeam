# Baseline detectors are an irreducible floor

The first built-in baseline detects credentials and authentication material, Taiwan personal identifiers and common contact identifiers, financial identifiers with applicable checksum validation, sensitive environment/key/certificate paths, and common secret-bearing field names. Images remain unavailable by default and PDF/Office content enters only through Sanitized Sidecars. Names, addresses, internal project codenames, and other semantic company-confidential content are supplemented by Company Base Policy and the optional company `/v1` classifier. Baseline matches only add Protected Exclusions and no Provider Supplemental Policy can disable them.
