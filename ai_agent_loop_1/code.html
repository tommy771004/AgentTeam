02_execution_rules.md

sync_alt

Pattern 1: Turn-based

Model:1 Input = 1 Action
Trigger:User Request (Synchronous)
Validation:Output schema match
Anti-pattern:Infinite looping without user ACK
route

Pattern 2: Goal-based

Model:Autonomous Iteration
Trigger:Complex Objective Assigned
Validation:Sub-task completion metrics
Anti-pattern:Drifting from primary objective (Hallucination)
schedule

Pattern 3: Time-based

Model:Cron-job style
Trigger:Temporal Schedule (CRON expr)
Validation:Execution timestamp & duration limit
Anti-pattern:Overlapping execution windows
bolt

Pattern 4: Proactive

Model:Event-driven
Trigger:System Event / Webhook Payload
Validation:Event signature verification
Anti-pattern:Reaction loops (Event triggers another event)
